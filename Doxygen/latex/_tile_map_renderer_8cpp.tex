\doxysubsection{Detailed Description}
Implementation of the Tile\+Map\+Renderer raycasting renderer. 

Rendering pipeline per frame:\+
\begin{DoxyEnumerate}
\item Column pass — DDA-\/casts one ray per COLUMN\+\_\+\+STEP pixels, fills managed\+Columns and writes perpendicular distances to ZBuffer.
\item Ceiling pass — CPU-\/rasterises ceiling into a scaled framebuffer, uploads as a single GPU texture, draws one full-\/screen quad.
\item Floor pass — Same as ceiling but below the horizon.
\item Wall pass — Draws textured/\+coloured wall strips via AEGfx\+Tri\+Add, batched by tile type and fog key to minimise GPU draw calls. 
\end{DoxyEnumerate}
