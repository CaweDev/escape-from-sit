\doxysubsection{Detailed Description}
Singleton that manages all \doxylink{namespace_u_i}{UI} managers, services, rendering and input. 

Responsibilities:\+
\begin{DoxyItemize}
\item Owns the shared quad mesh for all \doxylink{namespace_u_i}{UI} rendering
\item Manages active \doxylink{class_u_i_1_1_canvas}{Canvas} objects
\item Processes mouse input and dispatches to \doxylink{namespace_u_i}{UI} elements
\item Provides coordinate conversion utilities 
\end{DoxyItemize}
