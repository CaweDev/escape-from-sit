\doxysubsection{Detailed Description}
Defines position, size, and anchoring for \doxylink{namespace_u_i}{UI} elements (Unity-\/style). 

Coordinate system:\+
\begin{DoxyItemize}
\item anchor\+Min/\+anchor\+Max:\+ Normalized (0-\/1) relative to parent
\item pivot:\+ Normalized (0-\/1) relative to this element (0,0 = bottom-\/left, 1,1 = top-\/right)
\item anchored\+Position:\+ Offset in pixels from anchor midpoint
\item size\+Delta:\+ Size offset or fixed size 
\end{DoxyItemize}
