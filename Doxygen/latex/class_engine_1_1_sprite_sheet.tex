\doxysubsection{Detailed Description}
Shared data asset representing a spritesheet with named animations. 

Holds a texture reference, grid layout (rows x cols), and a map of named Animation\+Clips. Multiple Sprite\+Sheet\+Renderers can share the same \doxylink{class_engine_1_1_sprite_sheet}{Sprite\+Sheet} while each playing different animations independently.

Cached by \doxylink{class_engine_1_1_asset_manager}{Asset\+Manager} via Get\+Sprite\+Sheet().
