\doxysubsection{Detailed Description}
Renders a small top-\/down view of the tile map with player position. 

This element tracks the player\textquotesingle{}s position and renders a local neighborhood of tiles. It supports arbitrary rotation (tracking player heading) and uses a custom clipping algorithm to ensure tiles don\textquotesingle{}t overflow the \doxylink{namespace_u_i}{UI} bounds.
