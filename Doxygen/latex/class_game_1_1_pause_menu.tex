\doxysubsection{Detailed Description}
Escape-\/key pause overlay with Resume, Restart, and Main Menu. 

Attach to the \doxylink{class_game_1_1_player}{Player} Game\+Object (same as \doxylink{class_game_1_1_player_h_u_d}{Player\+HUD}). Manages its own \doxylink{class_u_i_1_1_canvas}{Canvas} at a high sort-\/order so it renders above the HUD.
