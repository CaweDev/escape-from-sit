\doxysubsection{Detailed Description}
Root container for \doxylink{namespace_u_i}{UI} elements, similar to Unity\textquotesingle{}s \doxylink{class_u_i_1_1_canvas}{Canvas}. 

All \doxylink{namespace_u_i}{UI} elements must be children of a \doxylink{class_u_i_1_1_canvas}{Canvas} to be rendered. Handles resolution scaling and provides the root coordinate system.
