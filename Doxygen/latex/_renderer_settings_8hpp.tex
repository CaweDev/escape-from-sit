\doxysubsection{Detailed Description}
Shared rendering configuration loaded from Assets/\+\+Config/\+\+Engine/\+rendering.\+json. 

Exposes tunable rendering constants (near-\/plane clamps, fog LUT precision, door intersection thresholds) as static members so that Tile\+Map\+Renderer, Door\+Renderer, and Projection\+Helper all read from one authoritative source.

Call Renderer\+Settings::\+\+Initialize() once at startup (before any renderer is used). If not called, sensible defaults matching the shipped values are used.
