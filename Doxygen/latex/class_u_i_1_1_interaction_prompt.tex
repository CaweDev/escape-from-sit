\doxysubsection{Detailed Description}
Displays an interaction prompt below the crosshair. 

Shows text like "{}\+[\+E]\+ Open"{} when the player is looking at an interactable object. Uses the \doxylink{namespace_u_i}{UI} hierarchy system with \doxylink{class_u_i_1_1_text}{Text} as a child.
