\doxysubsection{Detailed Description}
Generates collision surfaces from \doxylink{class_engine_1_1_tile_map}{Tile\+Map} wall tiles. 

Attach this to the same \doxylink{class_engine_1_1_game_object}{Game\+Object} as a \doxylink{class_engine_1_1_tile_map}{Tile\+Map} component. It will automatically use the tilemap for collision detection.
