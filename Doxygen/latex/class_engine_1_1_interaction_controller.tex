\doxysubsection{Detailed Description}
Player component that detects and interacts with \doxylink{class_engine_1_1_interactable}{Interactable} objects. 

Attach this component to the player\textquotesingle{}s camera \doxylink{class_engine_1_1_game_object}{Game\+Object}. It will:\+
\begin{DoxyItemize}
\item Only run when \doxylink{class_engine_1_1_camera_abf6ed02ded65f0cb5970c5ba56a53370}{Camera::\+main}-\/\texorpdfstring{$>$}{>}game\+Object matches this-\/\texorpdfstring{$>$}{>}game\+Object
\item Raycast from screen center to find interactable objects
\item Update crosshair and prompt \doxylink{namespace_u_i}{UI}
\item Highlight the targeted sprite
\item Handle interaction input 
\end{DoxyItemize}
