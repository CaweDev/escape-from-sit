\doxysubsection{Detailed Description}
3D raycasting renderer for tile-\/based maps. 

Renders a first-\/person 3D view using the DDA raycasting algorithm, similar to classic games like Wolfenstein 3D and DOOM. Each frame it:\+


\begin{DoxyEnumerate}
\item Casts one ray per COLUMN\+\_\+\+STEP pixels across the screen width (the "{}column pass"{}).
\item Renders ceiling and floor into scaled CPU framebuffers, then uploads them as a single GPU texture each via AEGfx\+Texture\+Load\+From\+Memory.
\item Renders textured wall columns as GPU triangle strips, batched by tile type and fog key to minimise draw calls.
\end{DoxyEnumerate}\hypertarget{_tile_map_renderer_8hpp_perf}{}\doxysubsection{\texorpdfstring{Performance notes}{Performance notes}}\label{_tile_map_renderer_8hpp_perf}

\begin{DoxyItemize}
\item COLUMN\+\_\+\+STEP controls the horizontal raycast granularity. Higher = fewer rays = faster, but columns appear wider and "{}blocky"{}. Default 8.
\item fb\+Scale controls the floor/\+ceiling framebuffer resolution relative to screen size. 0.\+25 = quarter-\/res (very fast, pixelated), 0.\+5 = half-\/res (good balance), 1.\+0 = full-\/res.
\item Fog is applied via a pre-\/computed look-\/up table (fog\+LUT) to avoid per-\/pixel expf() calls. The LUT is rebuilt only when Camera::\+main\textquotesingle{}s fog\+Distance changes.
\end{DoxyItemize}\hypertarget{_tile_map_renderer_8hpp_pipeline}{}\doxysubsection{\texorpdfstring{Render pipeline order}{Render pipeline order}}\label{_tile_map_renderer_8hpp_pipeline}
Ceiling (framebuffer quad) → Floor (framebuffer quad) → Walls (GPU strips, on top) Sprites are drawn after this renderer by Sprite\+Renderer, using ZBuffer for occlusion.
