\doxysubsection{Detailed Description}
\doxylink{class_engine_1_1_component}{Component} that renders animated sprites from a \doxylink{class_engine_1_1_sprite_sheet}{Sprite\+Sheet}. 

References a shared \doxylink{class_engine_1_1_sprite_sheet}{Sprite\+Sheet} asset and manages per-\/instance playback of named animation clips. Supports both 2D and 2.\+5D billboard rendering.
