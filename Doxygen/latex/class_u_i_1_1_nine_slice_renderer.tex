\doxysubsection{Detailed Description}
Static utility class for drawing 9-\/sliced images. 

Builds a transient 18-\/triangle mesh with correct per-\/patch UVs, draws it in a single draw call, then frees it.

Border widths are read from the texture\textquotesingle{}s Nine\+Slice\+Border (set via \doxylink{class_u_i_1_1_texture2_d_a7338a1a6aced4ea41cad1709b6c8e367}{Texture2\+D::\+\+Set\+Slice\+Border}). The border is an intrinsic property of the texture asset.
