\doxysubsection{Detailed Description}
First-\/person 3D renderer that raycasts against a \doxylink{class_engine_1_1_tile_map}{Tile\+Map}. 

Attach this component to any \doxylink{class_engine_1_1_game_object}{Game\+Object} that also has a \doxylink{class_engine_1_1_tile_map}{Tile\+Map} component. Assign floor, ceiling, and wall sprites by tile-\/type ID using the Set\texorpdfstring{$\ast$}{*}\+Sprite family of methods.

\begin{DoxyParagraph}{Render order}
Returns FLT\+\_\+\+MAX from \doxylink{class_engine_1_1_tile_map_renderer_a040e6420f4daca74df094e2b688a603e}{Get\+Sorting\+Key()} so the \doxylink{class_engine_1_1_i_renderer}{IRenderer} system always draws this renderer before all other renderers (sprites, \doxylink{namespace_u_i}{UI}, etc.).
\end{DoxyParagraph}
\begin{DoxyParagraph}{Floor/\+\+Ceiling rendering}
Floor and ceiling are rendered into CPU-\/side RGBA framebuffers at (screen\+Width \texorpdfstring{$\ast$}{*} fb\+Scale) × (screen\+Height \texorpdfstring{$\ast$}{*} fb\+Scale) resolution, then uploaded to the GPU as a transient texture each frame and drawn as a single full-\/screen quad. Pixel data is loaded once from disk via Windows Imaging \doxylink{class_engine_1_1_component}{Component} (WIC) when Set\+Floor\+Sprite /\+ Set\+Ceiling\+Sprite is called.
\end{DoxyParagraph}
\begin{DoxyParagraph}{Wall rendering}
Walls use the traditional Alpha\+Engine AEGfx\+Tri\+Add pipeline. Column strips are sorted by tile type and fog key so consecutive same-\/type columns can be batched into a single mesh, keeping GPU draw calls low. 
\end{DoxyParagraph}
