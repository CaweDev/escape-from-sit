\doxysubsection{Detailed Description}
Static service for full-\/screen fade-\/to-\/black transitions. 

Uses a dedicated \doxylink{class_u_i_1_1_canvas}{Canvas} (sort\+Order 9999) with a full-\/screen black \doxylink{class_u_i_1_1_image}{Image}. Supports smooth ease-\/in-\/out interpolation with completion callbacks.
