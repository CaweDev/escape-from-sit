\doxysubsection{Detailed Description}
Intermediate scene that displays loading \doxylink{namespace_u_i}{UI} between scene transitions. 

Used by Scene\+Manager::\+\+Load\+With\+Screen. Shows a "{}\+LOADING..."{} text with animated dots and a progress bar, then deferred-\/loads the target scene.
