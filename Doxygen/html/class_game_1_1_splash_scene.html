Detailed Description

Splash screen that shows the DigiPen logo with horror effects.

Timeline: FadeIn -> HoldAndExpand -> Flicker (1 dip, swap to logo2) -> FinalFlicker (1 dip, swap to white) -> FinalHold -> FadeOut Transitions automatically to MainMenu. Skippable via key/click.
