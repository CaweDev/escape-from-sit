Detailed Description

Shared data asset representing a spritesheet with named animations.

Holds a texture reference, grid layout (rows x cols), and a map of named AnimationClips. Multiple SpriteSheetRenderers can share the same SpriteSheet while each playing different animations independently.

Cached by AssetManager via GetSpriteSheet().

Define or overwrite a named animation clip.

If an animation with the same name already exists, it is silently overwritten. Frame indices are row-major (0 = top-left cell).

Parameters
nameUnique name for this animation (e.g. "idle", "walk")
startFrameIndex of the first frame in the clip
frameCountNumber of frames in the clip
fpsPlayback speed in frames per second
loopWhether the animation loops (default: true)
