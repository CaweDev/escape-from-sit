Detailed Description

First-person 3D renderer that raycasts against a TileMap.

Attach this component to any GameObject that also has a TileMap component. Assign floor, ceiling, and wall sprites by tile-type ID using the Set*Sprite family of methods.

Render order
Returns FLT_MAX from GetSortingKey() so the IRenderer system always draws this renderer before all other renderers (sprites, UI, etc.).
Floor/Ceiling rendering
Floor and ceiling are rendered into CPU-side RGBA framebuffers at (screenWidth * fbScale) × (screenHeight * fbScale) resolution, then uploaded to the GPU as a transient texture each frame and drawn as a single full-screen quad. Pixel data is loaded once from disk via Windows Imaging Component (WIC) when SetFloorSprite / SetCeilingSprite is called.
Wall rendering
Walls use the traditional AlphaEngine AEGfxTriAdd pipeline. Column strips are sorted by tile type and fog key so consecutive same-type columns can be batched into a single mesh, keeping GPU draw calls low.
