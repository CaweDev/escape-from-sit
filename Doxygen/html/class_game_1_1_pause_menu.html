Detailed Description

Escape-key pause overlay with Resume, Restart, and Main Menu.

Attach to the Player GameObject (same as PlayerHUD). Manages its own Canvas at a high sort-order so it renders above the HUD.

Hierarchy: Canvas (sort 500) └── Panel (overlay – full-screen dim) └── Panel (menu – centered box) ├── Text ("PAUSED") ├── Image (divider) ├── Button (Resume) ├── Button (Restart) └── Button (Main Menu)
