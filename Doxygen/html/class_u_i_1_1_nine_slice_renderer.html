Detailed Description

Static utility class for drawing 9-sliced images.

Builds a transient 18-triangle mesh with correct per-patch UVs, draws it in a single draw call, then frees it.

Border widths are read from the texture's NineSliceBorder (set via Texture2D::SetSliceBorder). The border is an intrinsic property of the texture asset.

9-Slice layout:

+--------+-----------+--------+
| TL | TC | TR | <- border.top (fixed height)
+--------+-----------+--------+
| ML | MC | MR | <- stretches vertically
+--------+-----------+--------+
| BL | BC | BR | <- border.bottom (fixed height)
+--------+-----------+--------+
border stretches border
